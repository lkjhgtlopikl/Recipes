#Кулинарная книга (Recipe Book)

Сайт для публикации, поиска и персонализированных рекомендаций кулинарных рецептов.  
Позволяет пользователям регистрироваться, создавать собственные рецепты с пошаговыми инструкциями и фотографиями, оценивать и комментировать блюда других авторов, а также сохранять понравившиеся рецепты в личные кулинарные книги.

**Ключевая особенность** — интеллектуальная система рекомендаций, которая на основе выставленных оценок и любимых ингредиентов предлагает рецепты, наиболее соответствующие вкусам пользователя (используется коэффициент Жаккара и диетические столы по Певзнеру).

---

##Основные возможности

-**Регистрация и авторизация** с хешированием паролей (bcrypt) и JWT-токенами.
-**CRUD-операции с рецептами**: создание, редактирование, удаление (автором), просмотр.
-**Ингредиенты**: добавление к рецепту с указанием количества и единиц измерения, автоматический расчёт КБЖУ.
-**Загрузка изображений** через Cloudinary (основное фото блюда и пошаговые фотографии).
-  **Оценки и комментарии**: возможность ставить оценку от 1 до 5 и оставлять текстовые отзывы.
-  **Кулинарные книги**: создание персональных подборок рецептов.
-  **Персональные рекомендации**:
  - анализ рецептов, оценённых пользователем на 4 и 5;
  - выделение любимых ингредиентов;
  - поиск рецептов с похожим составом (коэффициент Жаккара);
  - фильтрация по кухне, категории, типу приготовления и диетическому меню (столы Певзнера);
-**Фильтрация и поиск** по различным параметрам.
-**Адаптивный интерфейс** на React с использованием Bootstrap.

##   Алгоритм рекомендаций 

Сначала алгоритм получает популярные рецепты – это все рецепты из базы данных со средней оценкой выше 4 баллов. Затем алгоритм получает данные для отбора рекомендованных рецептов из базы – ингредиенты, тип приготовления, кухня, категория – на основании рецептов, которые пользователь оценил выше 4 баллов, добавил в какую-либо свою кулинарную книгу или разместил на платформе как автор. Далее определяется какие диетические столы рекомендованы пользователю в соответствии с его заболеваниями, для этого пользователь заполняет форму, ссылка на которую находится в его личном профиле.    Если пользователь не отметил ни одного заболевания, столы не учитываются при выборе рецептов, если отметил - учитываются. Затем алгоритм выбирает из базы рецепты, данные которых соответствуют данным для отбора рекомендованных рецептов, но не учитывает рецепты, на которых этот отбор основывался. Выбранные рецепты оцениваются по ингредиентам с помощью коэффициента Жаккарда, описанного в предыдущем подразделе. В список рекомендованных попадают только рецепты с коэффициентом Жаккарда выше среднего по данной выборке. Если пользователь не авторизован на сайте или у него нет оцененных, сохраненных или созданных рецептов, алгоритм рекомендует ему рецепты с оценкой выше 4, иначе – выбранные в соответствии с параметрами.
